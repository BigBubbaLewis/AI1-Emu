# AI1 Emu v0.3.2 — one folder and complete public source

Existing v0.3.1 installations can use Settings → Check for updates → Download,
then close the app to install and reopen it. This is a main-app update; the four
v0.3.1 companions are unchanged. The owner reported DS working in v0.3.1 on an
original Switch. No new DS/Switch Lite performance claims are made here.

On startup, v0.3.2 combines `SD:/switch/retroverse/` into `SD:/switch/ai1emu/`.
It compares copies byte-for-byte before removing sources, removes verified ROM
duplicates (including flat versus console-subfolder duplicates with the same
filename), and maps the old saves/states to the retained cartridge. Different
existing AI1 files are never overwritten; older conflicting files are retained
under `ai1emu/legacy-conflicts/`. See `ai1emu/migration-report.txt` for actions.
Unknown legacy files are retained. The obsolete old main NRO is removed only
after data transfers finish. The old folder is removed only when empty.

The first merge may take time proportional to your ROM collection. Progress is
shown; Plus+Minus pauses the merge between I/O chunks. A failed copy retains
the source and can retry next launch. Free space is needed temporarily for each
unique file being copied. No Nintendo system or HOME-menu files are changed.

Tests cover duplicate/cross-folder ROMs, GBA and DS saves, conflicting existing
files, cancellation before/during a copy, retry, and invalid destination safety.
The Switch build compiled. The merge itself still needs a real-Switch test.

Project/source hub: https://ai1emu-updates.freegamez.workers.dev/
Source browser: https://ai1emu-updates.freegamez.workers.dev/developer/
The full archive includes app and core source, build/artwork tools, tests,
Cloudflare service, notices and dependency source. Browser edits download a
changed local file; compiling the app requires devkitPro. Publishing requires
authorized Cloudflare access. See `COLLABORATING.md`.

Fresh installations use the complete package. Old GBA-only installations retain
their stable update channel, so they are not offered a main NRO without the
required multi-console companions. ROMs, proprietary firmware, console keys
and commercial artwork are not published.
