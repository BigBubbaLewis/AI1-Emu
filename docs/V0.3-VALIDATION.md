# AI1 Emu v0.3 validation — November 3, 2026

Completed locally:

- mGBA rebuilt with both GB and GBA engines enabled; main `AI1Emu.nro` compiled and linked using installed devkitA64 GCC 16.1.0.
- melonDS software/interpreter core compiled first; independent `melonds.nro` linked.
- FCEUmm, Snes9x and Genesis Plus GX then compiled and linked individually into their own companion NROs.
- All five files have valid NRO headers and embedded ASET assets. The four companion ELFs have no unresolved external symbols.
- Host platform test passed: supported/unsupported extensions, recursive library, category filters, isolated saves, flat GBA legacy-save reuse, nested-name isolation, and bottom-screen coordinate mapping for all three DS layouts.
- Host touch regression test passed: tabs, view toggle, console category taps, selection, launch action, settings/footer, swipe/inertia, synthetic mouse suppression and empty-library hit handling.
- Artwork test passed across nine console databases, recursive folders, offline missing-art behavior, preserved custom art, and SHA-1 recognition of a renamed synthetic non-game fixture.
- Updater manifest and install tests passed, including invalid downloads and rollback on rename failure.
- Windows preview built from the shared UI renderer. Actual Cover, Cartridge, Settings and About captures are in `Windows-Preview/screenshots/v03-*.png`. Development-only cover caches are excluded from the Switch package.
- Final packaging script checks all five NRO hashes against ZIP entries, verifies install paths and rejects obvious keys/ROM/development-tool entries. Source/notices are deliberately included separately for redistribution compliance.

Not verified:

- No new core was executed on a physical Switch or Switch Lite. Compilation and host UI tests do not verify core execution, full-speed performance, audio, save compatibility or chainloading.
- Actual DBI MTP device transfers for the new recursive multi-console tool require hardware testing. Its embedded PowerShell syntax and offline artwork engine were checked locally.
- Online thumbnail availability varies by release and source; offline tests do not establish availability of every cover.
- DSi firmware/NAND boot compatibility, DSi in-game saves, and DS game-dependent peripherals are untested. DSi save states are explicitly unsupported upstream.
- Dekopon source was inspected, but no 3DS/2DS binary was built. Required NXVK/dynarmic dependencies and its native frontend need a separate integration pass. No N64, PS1 or PSP integration was attempted.

The stable v0.2.2 Cloudflare release and working-version backup remain intact. The new package is a local test release requiring a complete install, including companions.
