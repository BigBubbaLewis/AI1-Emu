# AI1 Emu v0.3.3 — Nintendo 64

Nintendo 64 is an experimental, separately linked Mupen64Plus-Next companion.
The working v0.3.2 build is backed up in backups/AI1-v0.3.2-before-N64.zip.

## Install

Extract the complete package into the SD card root and merge switch/ai1emu.
Keep your existing ROMs and saves. Put legally obtained, uncompressed .z64,
.v64 or .n64 cartridges in switch/ai1emu/roms/n64 (nested folders also work).
No external BIOS is required for standard cartridge emulation. No commercial
ROMs, artwork, proprietary firmware, 64DD disks or Transfer Pak games are bundled.
64DD and Transfer Pak integration are outside this release.

Existing v0.3.1/v0.3.2 users: Settings > Check for updates, download, then
install and reopen. In the updated app, check for updates again to download
and install the missing N64 companion. Reopen after installation. The complete
ZIP already contains the companion. Network access is only on request.
Launch through the AI1 HOME tile or full-memory Homebrew Menu application mode;
Album applet mode is refused for N64. No overclocking is requested.

## Controls

Switch A = N64 A; Switch B = N64 B; left stick = analog stick;
right stick = four C buttons; D-pad = D-pad; L/R = L/R; ZL = Z; Plus = Start.
Minus + ZR saves a state; Minus + ZL loads it. Plus + Minus returns to the library.
Game-dependent states use the core's own serialization; cross-core/version
state compatibility is not guaranteed. Ordinary cartridge saves and the first
controller's memory pak are stored in the game-specific saves/n64 prefix.
Saves are isolated by console and relative ROM path. Existing GBA saves retain
their current paths. Do not rename/move a ROM without moving its associated saves.

## Renderer, performance and limitations

Uses GLideN64 hardware OpenGL, HLE RSP, native 320x240 rendering, and one controller.
A libnx-compatible dynamic recompiler is selected only if an own-process JIT
mapping succeeds. Otherwise cached interpretation is used and will be much slower.
logs/core-n64.log records the actual renderer, CPU selection and startup phases.
A cooperative Plus/Minus exit check runs at emulated video interrupts; a stalled
GPU/driver cannot be reliably recovered by this check.

Compilation and Windows tests do not establish Switch gameplay compatibility.
N64 booting, graphics correctness, audio pacing, game controls, save persistence,
state round trips, library return, docked mode and performance must be tested on
an actual Switch. Some games may be too slow or incompatible without overclocking.
The Windows UI preview remains UI-only; the development core smoke test is separate.

## Artwork and source

Use the included self-contained Windows PC-tools; no Node.js installation needed.
The N64 database comes from libretro/libretro-database metadat/no-intro;
matching uses known hashes and normalized regional filenames. Byte-swapped ROMs
without a matching hash fall back to filenames. Missing covers remain clean
placeholders; offline operation and custom covers are preserved. Commercial
covers are downloaded only into the user's personal cache, never in this package.

Upstream: https://github.com/libretro/mupen64plus-libretro-nx
The pinned revision is recorded in vendor/mupen64plus-next/AI1-UPSTREAM.json.
Mupen64Plus-Next and components retain their own GPL and other license notices.
The complete corresponding-source archive includes the core and AI1 changes.
Local Switch changes: current libnx JIT alias API, 4096-byte host pages,
explicit JIT capability probe/release, and cooperative exit at VI interrupts.
The previous core runners are preserved; their platform IDs remain 0 through 9.
N64 is appended as platform 10.

and scripts/test-n64-windows.sh for reproduction (SDL2, MinGW, NASM, Python required).

only another PNG filename. The tool now follows bounded, same-directory aliases before
image decoding, indexes actual available cover names, and reports relative ROM paths.
Repeated MTP listings of the same path are suppressed. Distinct files in separate
folders remain separate; the tool never deletes ROMs to hide duplicates.
