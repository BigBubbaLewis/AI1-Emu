# AI1 Emu v0.5.4 Preview

This preview adds an on-demand online cheat catalog to the shared in-game menu, improves DS audio underrun handling, protects the previous settings/state/cheat file during replacement, and adds a touchscreen arrow for console filters beyond the visible row.

## Install
Back up your saves. Extract the Switch Package ZIP directly into the SD-card root and merge the switch folder. The app is SD:/switch/ai1emu/AI1Emu.nro. Keep the included cores folder beside it. Add your own legally obtained, uncompressed ROMs under roms/<console>/. Launch using full-memory Homebrew Menu application mode. No games, proprietary firmware or console keys are supplied.

## Online cheats
Open the AI1 in-game menu with Plus and Minus together, choose Cheats, then Download via database. Select the exact game/region/revision and code format. The app downloads only that entry, checks its size and SHA-256, caches it in cheats/cache and merges new codes without replacing existing codes. Downloaded codes are disabled until you enable them. Cached/saved cheats work offline.

The hosted collection has 16,486 entries for GB, GBC, GBA, NES, SNES, Genesis, Master System, Game Gear, DS and N64. Entry coverage does not guarantee a correct code for every game, revision or core. Matching uses normalized filenames and explicit release selection; checksum-based ROM matching is not implemented for cheats. Website-wide internet search is not implemented. Unknown hacks receive no guessed codes. Source: libretro/libretro-database, CC BY-SA 4.0. Upstream raw-memory handlers are excluded.

The external Dekopon 3DS companion retains its own menu, cheat format, saves and exit behavior. AI1's download menu is not integrated into Dekopon or DSi. DS/DSi/N64/3DS performance remains game-specific; no new hardware benchmarks are claimed.

## Supported files
GBA .gba; GB .gb; GBC .gbc; NES .nes; SNES .sfc/.smc; Genesis .md/.gen/.smd (supported .bin); Master System .sms; Game Gear .gg; DS .nds; DSi .dsi or DSi-only .nds; N64 .z64/.v64/.n64; experimental decrypted 3DS .3ds/.cci/.cxi/.zcci/.zcxi. CIA installers are not supported.

Supply any required firmware yourself in system/<console>/. DS optional dumps: nds/bios7.bin, bios9.bin, firmware.bin. DSi requires dsi/dsi_bios7.bin, dsi_bios9.bin, dsi_firmware.bin, dsi_nand.bin. DSi states are unsupported. See the existing core support documentation for special SNES firmware.

## Validation and limitations
The main NRO and five AI1 companions compiled with devkitA64 GCC 16.1.0. The upstream Dekopon binary is unchanged. Catalog integrity tests and service matching/error tests passed. Final host-test results accompany this release. Compilation and host tests do not prove Switch gameplay, correct cheat effects, performance or audio quality. Test normal saves, states, touch, audio and returning to the library on your Switch before requesting reviews.

DS audio keeps the startup buffer but no longer deliberately pauses for a full refill after each underrun. This reduces one possible source of repeated gaps; it does not promise full-speed emulation or eliminate all audio problems. Exit-time audio diagnostics are in logs/core-nds.log.

Previous file replacement backups use .previous. This protects against failed rename/installation; it is not a guarantee against SD corruption or sudden power loss. Keep independent save backups.
