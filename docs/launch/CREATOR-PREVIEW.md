# Creator preview

AI1 Emu — One library. Multiple consoles. Your way to play.

An independent Nintendo Switch homebrew frontend with a unified library, touch/controller navigation, custom covers, themes and a shared in-game menu for integrated cores. Supply your own legally obtained games and required firmware.

This is a preview. Identify the exact version, device, clocks, console, game and scene in a review. DS audio and experimental N64/3DS performance need game-specific testing. 3DS launches a separate Dekopon companion with its own menu. Windows UI captures demonstrate the real renderer, not emulator performance.
