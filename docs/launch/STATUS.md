# Public preview status — November 24, 2026

This is preview development. The owner reports working gameplay on an original Switch in earlier builds. No standardized hardware benchmarks are published.

Release-readiness work includes an online per-game cheat catalog, safer persistence, host regressions and DS audio investigation. Hosting the service does not mean installed app versions support it. Cheats must match the game region, revision and core-supported format.

3DS uses external Dekopon with its own menu. Direct return to AI1 and native AI1 menus are not integrated. Do not advertise full-speed 3DS Pokemon gameplay.

The screenshots in docs/images/v0.5-ui are actual Windows shared-renderer captures of the frozen v0.5.0 UI snapshot. Sample cards, states, cheats, battery and background scene are fixtures, not Switch gameplay. Capture notes and provenance accompany them.
