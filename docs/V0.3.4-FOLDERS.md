# AI1 Emu v0.3.4 — automatic console folders

At startup, the application creates roms/<console> for every platform in the
supported-console registry. This includes roms/n64 after an in-app update;
users no longer need to extract the complete package merely to create folders.
Future console integrations added to that registry get their folders automatically.
Existing folders and files are preserved; ROMs are not moved or deleted.
Folders use the current data root, normally sdmc:/switch/ai1emu/.
Unsupported consoles are not enabled simply by creating a folder.

Update from Settings, install, and reopen AI1 Emu once to create missing folders.
GBA/GB/GBC/NES/SNES/Genesis/SMS/GG/DS/DSi/N64 support and controls are unchanged.
The existing companion NROs are retained from the working v0.3.3 package.
N64 gameplay and performance still require physical Switch testing.
